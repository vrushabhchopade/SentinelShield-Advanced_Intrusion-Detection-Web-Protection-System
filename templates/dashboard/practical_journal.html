school Experiment Title & Objectives

Investigation of Modular Web Application Firewall (WAF) Heuristics & Rate-Limiting Mitigations

Primary Objective: Build, configure, and evaluate an educational defensive cybersecurity platform (SentinelShield) capable of real-time HTTP payload inspection, signature tokenization, automated rule matching, sliding-window rate limiting, and forensic SOC alerting without causing performance degradation or denial of legitimate application services.

psychology Forensic Findings & Evaluation Analysis

1. Input Normalization: Multiple-pass bounded URL decoding effectively dismantled evasion attempts involving nested hex encoding (e.g. %252e%252e%252f normalized safely to ../).

2. Confusion Matrix Accuracy: Across the standard 16-case benchmark suite, SentinelShield achieved 100% precision and zero recorded false positives on legitimate queries.

3. Rate Limiting Resilience: Enforcing strict thresholds (10 req/min) on authentication pathways prevented automated brute-force password spraying while maintaining normal responsiveness for authenticated analysts.

warning Defensive Limitations & Future Hardening
  • Signature-based detection cannot detect zero-day vulnerabilities lacking predefined heuristic patterns.
  • LocMemCache rate limiting is isolated per-process; enterprise scale requires distributed cluster storage (Redis).
  • Application-level WAF operates at Layer 7; volumetric Layer 3/4 network DDoS must be mitigated at upstream scrubbers.
