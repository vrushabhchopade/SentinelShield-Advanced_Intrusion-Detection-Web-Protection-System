code Writing Custom Detection Rules

When authoring regular expressions in Detection Rules, adhere to defensive best practices:

SQLi Pattern: (?i)\bUNION\s+(?:ALL\s+)?SELECT\b
XSS Pattern: (?i)<\s*script\b[^>]*>
Traversal Pattern: (?i)(?:\.\./|\.\.\\|\.\.%2f)
CMDi Pattern: (?i)(?:[;&|`]\s*(?:cat|ls|whoami|sh)\b)

Note: All regular expressions run within bounded 16KB buffers with bounded 2-pass URL decoding to neutralize ReDoS threats.
